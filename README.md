# Next.js 15 TypeScript Tailwind Starter

This repository contains a minimal setup for a Next.js 15 application using TypeScript and Tailwind CSS.

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```
2. Run the development server:
   ```bash
   npm run dev
   ```

For more information, see the [Next.js documentation](https://nextjs.org) and the [Tailwind CSS documentation](https://tailwindcss.com).
